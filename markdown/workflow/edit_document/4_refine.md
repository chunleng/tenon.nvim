## Purpose
Ensure documentation is concise and free of redundancy

## Process
1. Read the document
2. Check for redundancy that relates to the goal:
   - Repeated information → consolidate
   - Redundant sections → merge or remove
   - Duplicate explanations → keep clearest version
3. Check for conciseness that relates to the goal:
   - Remove filler words and phrases
   - Tighten verbose sentences
   - Simplify complex phrasing
4. Edit target file directly

## Refinement Rules
- Each sentence must: convey new information, explain a concept, or guide action
- No repetition across sections
- Active voice preferred
- Simple words over complex when equivalent

## Workflow Step Artifact
None (document modified in place)
