## Process
1. Based on the decision from move 2, determine the target file:
   - New: choose a descriptive filename under `markdown/directive/`: use `*_attitude.md` for behavior-steering, `*_basics.md` for knowledge-boosting, or a descriptive name if neither fits
   - Update: use the existing directive file
2. Research online for how to best encourage the desired agent behavior, or what resources/knowledge are needed to solve the problem. This step is optional: if you have no good search idea, skip the search rather than forcing one
   - Present the findings to the user and let them decide what to adopt
   - Only adopted findings inform the directive
3. Edit the target file to address the root cause from move 1, incorporating the adopted research findings. If updating an existing directive, modify it in place rather than rewriting from scratch
4. Present the directive to the user: summarize what it does and how it addresses the root cause
5. If the user requests changes, loop back to process step 3 with the feedback
6. If the user confirms, the choreo ends
