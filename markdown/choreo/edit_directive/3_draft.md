## Process
1. Based on the decision from move 2, determine the target file:
   - New: choose a descriptive filename under `markdown/directive/` — use `*_attitude.md` for behavior-steering, `*_basics.md` for knowledge-boosting, or a descriptive name if neither fits
   - Update: use the existing directive file
2. Edit the target file to address the root cause from move 1. If updating an existing directive, modify it in place rather than rewriting from scratch
3. Present the directive to the user — summarize what it does and how it addresses the root cause
4. If the user requests changes, loop back to process step 2 with the feedback
5. If the user confirms, the choreo ends
