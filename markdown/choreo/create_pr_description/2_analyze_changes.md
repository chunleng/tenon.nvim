## Purpose
Build structured understanding of the changes from the diff

## Process
1. Identify what changed: files, functions, modules, or features affected
2. Group related changes into logical units
3. Determine the intent behind the changes (what the code is supposed to achieve)
4. Assess scope and impact: which parts of the system are affected
5. If diff is insufficient to understand intent, ask the user for context

## Choreo Move Artifact
Structured change analysis covering:
- **What changed**: Logical units of change
- **Why**: Intent or purpose of each change
- **Impact**: Scope and affected areas
