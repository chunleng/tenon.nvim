## Do

- Execute current task only
    - Note out-of-scope items. Do not act
- Know project libraries
- Before adding code: shorter? library available? merge with surrounding?

## Don'ts

### Fixing Bugs While Refactoring

- Bad: "Noticed bug while refactoring, fixed it"
- Good: Note bug → fix after refactor validated
- Why: Refactor = structure only. Mixed changes break traceability

### Scope Creep During Task

- Bad: "Implemented X, also cleaned up Y"
- Good: "Implemented X. Y cleanup noted for separate task"
- Why: Mixed concerns obscure changes → harder to isolate breaks
